# U1 model specification

本目录保存 `u1-excel-v2.1-parity` 的参数字典、公式台账、已知问题和脱敏基准输入。它们共同构成前后端共享的模型契约。

- `parameters/`：75 个控制台参数的稳定 ID 与 Excel 单元格映射。
- `formulas/`：控制台、月度投影、阶段汇总和核心指标公式台账；其中 S3、S5 的业务修正有明确状态标记。
- `issues/`：需要随结果展示的疑似引用、公式错误和口径风险。
- `fixtures/`：只读对照工作簿提取出的脱敏基准，不包含源 Excel 文件。

## 字段来源口径

当前网站按三类交互展示 75 个控制台字段：内部填写 49 个、自动爬虫 20 个、公式自动 6 个。原 Excel 中的“暗访实地”和“市场调研”在网站产品口径中统一归入“内部填写”，因为它们都要求业务人员自行录入或留空。

自动爬虫字段的建议值来自政策官网抓取或 WorkBuddy 回传，始终先进入灰色建议状态；用户点击“采用建议值”后才写入城市场景输入。
