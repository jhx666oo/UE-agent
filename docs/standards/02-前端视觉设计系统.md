# 前端视觉设计系统

## 1. 设计定位

UE Agent 是长护险投资决策工作台。视觉必须帮助用户识别参数、来源、风险和计算状态，不承担营销展示任务。

首版采用浅色单主题。未完成专门设计和测试前，不增加暗色主题。

## 2. 颜色系统

页面只能使用语义 token。下表是首版权威值，实施时写入 `packages/ui/src/styles/tokens.css`。

### 2.1 基础颜色

| Token | 值 | 用途 |
|---|---|---|
| `--background` | `#F7F7F5` | 页面背景 |
| `--foreground` | `#1F2937` | 主文字 |
| `--surface` | `#FFFFFF` | 卡片、表格和弹层 |
| `--surface-subtle` | `#F2F4F3` | 次级区域和表头 |
| `--surface-selected` | `#E7F4F1` | 选中行、选中导航 |
| `--muted` | `#F3F4F6` | 禁用或弱强调背景 |
| `--muted-foreground` | `#667085` | 次级文字 |
| `--border` | `#E5E7EB` | 普通边框 |
| `--border-strong` | `#CBD5E1` | 强分隔和可调整边界 |
| `--primary` | `#0F766E` | 主操作和当前状态 |
| `--primary-hover` | `#115E59` | 主操作悬停 |
| `--primary-subtle` | `#CCFBF1` | 主色弱背景 |
| `--focus-ring` | `#0D9488` | 键盘焦点 |

### 2.2 业务状态颜色

| Token | 值 | 仅允许表达 |
|---|---|---|
| `--info` | `#2563EB` | 信息、链接、系统说明 |
| `--success` | `#15803D` | 已确认、已通过、计算成功 |
| `--warning` | `#B45309` | 低可信度、临期、待确认 |
| `--danger` | `#B42318` | 错误、阻断、失效和高风险 |

状态不能只依赖颜色，必须同时显示文字或图标。不得用绿色表示普通增长、用红色表示普通下降，除非该变化具有明确正负含义。

### 2.3 图表颜色

图表最多同时使用五个系列：

| Token | 值 | 默认系列 |
|---|---|---|
| `--chart-1` | `#0F766E` | 主结果或收入 |
| `--chart-2` | `#2563EB` | 第二指标或基金支付 |
| `--chart-3` | `#D97706` | 成本或风险 |
| `--chart-4` | `#64748B` | 参考、计划或历史 |
| `--chart-5` | `#B42318` | 亏损、阻断或异常 |

禁止为不同页面创建独立图表调色板。颜色含义跨页面保持一致。

## 3. 字体和数字

### 3.1 字体栈

```css
--font-sans: "PingFang SC", "Noto Sans SC", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

首版不从境外 CDN 加载字体。数字默认使用 `font-variant-numeric: tabular-nums`，只有参数编号、版本号和代码使用等宽字体。

### 3.2 字号

| 类型 | 字号/行高 | 用途 |
|---|---|---|
| 页面标题 | `24px / 32px` | 每页唯一 H1 |
| 区块标题 | `18px / 28px` | 主要区块 H2 |
| 小标题 | `16px / 24px` | H3 和组件标题 |
| 正文 | `14px / 22px` | 默认文字 |
| 表格 | `13px / 20px` | 高密度数据表 |
| 辅助文字 | `12px / 18px` | 来源、时间和字段说明 |

同一层级不得因页面不同任意改变字号。正文不得小于 12px。

## 4. 间距和尺寸

使用 4px 基准网格：`4, 8, 12, 16, 20, 24, 32, 40, 48, 64`。

| 场景 | 标准 |
|---|---|
| 页面左右内边距 | 桌面 24px，平板 20px，手机 16px |
| 页面区块间距 | 24px 或 32px |
| 卡片内边距 | 默认 20px，紧凑型 16px |
| 表单字段纵向间距 | 16px |
| 标签与输入框间距 | 8px |
| 图标与文字间距 | 8px |
| 默认控件高度 | 40px |
| 紧凑控件高度 | 36px |
| 表格数据行高度 | 44px |

禁止使用无来源的 `17px`、`23px`、`37px` 等任意间距。

## 5. 圆角、边框和阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | `6px` | Badge、小控件 |
| `--radius-md` | `8px` | 按钮、输入框、普通卡片 |
| `--radius-lg` | `12px` | Dialog、Sheet、大型容器 |

- 普通卡片使用 1px 边框，不使用明显投影。
- 浮层只允许使用一档柔和阴影：`0 8px 24px rgb(15 23 42 / 0.10)`。
- 不使用纯黑阴影、发光阴影和多层装饰阴影。
- Pill 仅用于筛选标签、状态标签和明确的分段选择，不作为所有按钮默认形状。

## 6. 图标

- 全站只使用 `@tabler/icons-react`。
- 默认尺寸 16px，工具栏和主要按钮可用 18px。
- 统一 `stroke={1.75}`。
- 图标按钮必须提供 `aria-label` 和 Tooltip。
- 不使用 Emoji 代替业务图标。
- 不手写 SVG path，不混用其他图标库。

## 7. 基础组件外观

### 7.1 Button

- `primary`：仅用于页面主操作，每个可视区域最多一个。
- `secondary`：普通操作。
- `outline`：筛选和次级操作。
- `ghost`：表格行操作和工具栏。
- `destructive`：删除、作废和不可逆操作。
- 默认高度 40px，紧凑型 36px。
- 文案必须单行，使用明确动词，例如“运行测算”“保存草稿”。
- 禁止同时出现多个文案不同但意图相同的主按钮。

### 7.2 Input、Select、Textarea

- 标签始终在控件上方，不使用 placeholder 代替标签。
- 单位放在后缀或标签中，不写入用户输入值。
- 错误信息放在控件下方，不能只用 Toast。
- 人工值、参考值和计算值必须有不同的只读与编辑状态。
- 禁用状态和只读状态必须可区分。

### 7.3 Card

只有在内容属于独立层级、可分组或可点击时使用 Card。普通页面区块优先使用标题、留白和分隔线，禁止所有内容都套卡片。

### 7.4 Table

- 表头使用 `--surface-subtle`，文字左对齐，数字列右对齐。
- 表头可固定，行高默认 44px。
- 金额、人数、月份和比例必须显示单位。
- 行悬停只改变背景，不产生位移或阴影。
- 操作列固定在右侧；超过三个操作时收进菜单。
- 空值显示 `-`，不可用显示“不可用”，错误显示具体原因。

### 7.5 Badge

Badge 只表达状态、来源类型、模型版本和风险等级。不能将普通分类全部做成彩色 Badge。

## 8. 可访问性

- 正文和背景对比度至少达到 WCAG AA 4.5:1。
- 大字号文字至少达到 3:1。
- 所有可交互控件支持键盘操作。
- 焦点环不得被移除，统一使用 2px `--focus-ring`。
- 表单标签必须和控件关联。
- 图标不能成为唯一信息载体。
- 动效遵循 `prefers-reduced-motion`。

## 9. 禁止的视觉模式

- AI 紫色渐变、霓虹光效、玻璃拟态和装饰性大渐变。
- 大面积纯色标题栏和无意义超大数字。
- 三张等宽卡片作为所有页面的默认布局。
- 多套圆角、阴影和按钮风格并存。
- 每个字段使用不同颜色强调。
- 为“看起来高级”而增加动态图标、粒子和滚动特效。
- 使用假数据制造看似完整的生产界面。
