# 前端验收检查表

## 1. 使用方式

新页面、新业务组件或重大视觉调整完成前，逐项检查。本清单是最低门槛，不因页面简单而省略适用项。

## 2. 架构和复用

- [ ] 已检查 `packages/ui` 和现有相似页面。
- [ ] 没有重复实现基础组件。
- [ ] 没有引入第二套 UI、图标、表格、表单或图表库。
- [ ] 新依赖已说明必要性、许可证和影响范围。
- [ ] 页面文件没有承载核心财务计算。
- [ ] 公共组件 API 使用业务无关的稳定命名。

## 3. 视觉一致性

- [ ] 页面只使用语义颜色 token。
- [ ] 没有硬编码品牌色、圆角、阴影和 z-index。
- [ ] 页面背景、内容层、边框和主色符合设计系统。
- [ ] 使用同一字体、字号和 4px 间距网格。
- [ ] Button、Input、Dialog、Table 等来自共享组件。
- [ ] 图标全部来自 Tabler，线宽和尺寸一致。
- [ ] 普通区块没有被无意义地全部包装成卡片。
- [ ] 没有渐变、玻璃拟态、霓虹光效或装饰动画。

## 4. 布局和响应式

- [ ] 桌面端符合统一应用骨架。
- [ ] 在 1440px、1280px、1024px、768px 和 390px 宽度检查过页面。
- [ ] 多栏布局在窄屏有明确降级方式。
- [ ] 表格在窄屏可水平滚动或切换为摘要视图。
- [ ] 没有水平溢出、文字截断、按钮换行和遮挡。
- [ ] Sticky 元素不会遮挡标题、表头和弹层。

## 5. 表单

- [ ] 每个字段有可见标签，placeholder 不承担标签职责。
- [ ] 单位、范围、精度和必填状态清楚。
- [ ] 参考值、人工值、计算值和只读值可区分。
- [ ] 错误显示在对应字段附近。
- [ ] 键盘可以完成填写、选择和提交。
- [ ] 重复提交被阻止。
- [ ] 未保存修改有明确提示。
- [ ] 零值不会被当作空值，空值不会被当作零值。

## 6. 数据表格和图表

- [ ] 表头固定且列名包含必要单位。
- [ ] 数字右对齐并使用等宽数字特性。
- [ ] 金额、百分比、人数和月份格式一致。
- [ ] 空值、不可用和错误使用不同文案。
- [ ] 排序、筛选、分页状态可以保留。
- [ ] 图表系列不超过五个，颜色含义一致。
- [ ] 图表有单位、图例或直接标签。
- [ ] Tooltip 展示与表格一致的精度和单位。
- [ ] 图表不是唯一的数据读取方式。

## 7. 页面状态

- [ ] 正常状态已验证。
- [ ] Loading 使用匹配最终结构的 Skeleton。
- [ ] Empty 说明原因和下一步。
- [ ] Error 显示具体问题和重试入口。
- [ ] 无权限状态说明缺少的权限。
- [ ] 数据过期状态显示更新时间和影响。
- [ ] 修改计算参数后，结果立即标记为 stale。
- [ ] Toast 没有替代必须持续显示的错误或风险。

## 8. UE 业务规则

- [ ] 正式结果绑定模型版本和输入快照。
- [ ] 参考值没有自动覆盖人工确认值。
- [ ] 数据来源、发布日期、适用区域和可信度可查看。
- [ ] 公式变更有版本记录和回归样例。
- [ ] 24 个月结果与 Excel 基准在约定容差内一致。
- [ ] 金额计算使用确定的精度和舍入策略。
- [ ] 大模型没有直接参与核心财务结果计算。
- [ ] 缺少必要输入时结果明确不可用。

## 9. 可访问性

- [ ] 正文和背景达到 WCAG AA 对比度。
- [ ] 所有交互元素有可见焦点。
- [ ] 图标按钮有 `aria-label` 和 Tooltip。
- [ ] 表单标签和输入控件正确关联。
- [ ] 状态不只依赖颜色表达。
- [ ] Dialog 打开后焦点正确进入，关闭后返回触发点。
- [ ] 页面支持 200% 浏览器缩放。
- [ ] 动效遵循 `prefers-reduced-motion`。

## 10. 代码和验证

- [ ] 格式化检查通过。
- [ ] ESLint 通过。
- [ ] TypeScript strict 检查通过。
- [ ] 单元和组件测试通过。
- [ ] 可访问性测试通过。
- [ ] Next.js 生产构建通过。
- [ ] 关键流程 Playwright 测试通过。
- [ ] 页面截图已经人工检查。
- [ ] 没有敏感信息、测试密钥和个人数据进入代码或快照。

## 11. 完成标准

只有在所有适用项通过、失败项有明确记录且没有阻断问题时，页面才可标记为完成。不能运行的检查必须说明原因和风险，不能默认视为通过。
