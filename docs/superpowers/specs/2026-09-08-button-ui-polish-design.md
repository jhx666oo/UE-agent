# UE-Agent 按钮 UI 统一设计

## 目标

修正当前中文按钮的字体突兀、图标比例不协调和顶部“新建项目”按钮容易换行的问题，建立适用于后续 Dashboard 页面的统一按钮视觉规范。

## 现状问题

- 公共按钮使用通用 `text-sm font-medium`，中文字体在当前回退字体链下视觉偏重。
- 顶部“新建项目”按钮没有为中文操作文案设置稳定的最小宽度。
- 图标尺寸和文字没有形成稳定比例。
- 按钮的行高没有明确约束，页面缩放或字体回退时容易出现垂直节奏不一致。

## 设计决策

1. 保留现有字体回退链：`PingFang SC`、`Noto Sans SC`、`Microsoft YaHei`、`system-ui`，不新增字体依赖。
2. 公共按钮默认使用 14px、常规字重、5 号行高，保持中文文案轻量且清晰。
3. 所有按钮继续保持单行显示，按钮尺寸通过高度和水平内边距控制，不通过压缩文字解决空间问题。
4. 图标默认 16px，顶部“新建项目”使用 15px 加号，减少图标对文字的抢占。
5. 顶部“新建项目”固定为横向布局，最小宽度 104px，桌面端不隐藏文字。
6. 保留青绿色主按钮和现有浅色主题，减少阴影，补充 active 位移反馈和统一 focus ring。
7. 本次只调整按钮组件和顶部栏，不修改业务数据、路由、模型公式或 Dashboard 信息架构。
8. 在 Web 全局样式中声明 `packages/ui/src` 为 Tailwind source，确保共享 UI 组件中的 utility class 生成真实 CSS。

## 验收标准

- “新建项目”在桌面端始终显示为一行“加号 + 新建项目”。
- 按钮文字使用统一的中文字体、字号、字重和行高。
- 公共按钮的 primary、secondary、outline、ghost、danger 变体均保持相同的排版基线。
- 按钮具备 hover、active、focus-visible、disabled 状态。
- 现有前端测试、类型检查、lint 和构建全部通过。
- 不引入新的 UI 或字体依赖。
- 共享 UI 组件中的 `inline-flex`、间距、高度、行高和交互状态 class 在浏览器计算样式中实际生效。
