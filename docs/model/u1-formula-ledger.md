# U1 公式台账

机器可读台账：[`u1.formulas.json`](../../packages/model-spec/formulas/u1.formulas.json)。以下文本保留当前 Excel 运算顺序和引用关系；公式修正必须新增模型版本。

## 公式字段与测算结果的依赖关系

`公式自动` 类字段（`C9`、`P3`、`S3`、`S5`、`B16`）由确定性引擎在测算时派生，写入 `U1Result.parameters`。前端读取 `result.parameters[fieldId]` 回显，**场景未测算（`status=draft`、`result=null`）时这些字段为空且只读，属预期行为**，不是缺失数据。

实现位置：`services/api/app/domain/u1/formulas.py`（计算）、`engine.py::calculate_u1`（`derived` 注入 `resolved`）、`apps/web/components/city-project-workbench.tsx`（回显）。

## 控制台公式

| 输出 | Excel 单元格 | 当前公式 | 状态 |
|---|---|---|---|
| C9 人口密度 | 控制台!E12 | `E6*10000/E16` | parity |
| P3 个人自付比例 | 控制台!E19 | `1-E18` | parity |
| S3 护理员日工作时段 | 控制台!E30 | `PI()*E28^2*E12*E7*(E9*0.6+E10*0.3+E11*0.1)` | parity |
| S5 站点覆盖失能客户上限 | 控制台!E32 | `PI()*E28^2*E12*E7*(E9*0.6+E10*0.3+E11*0.1)` | 已修正（原为 `…+E12*0.1`） |
| B16 初始投资总额 | 控制台!E51 | `E49+E50+(E41*E42+E36*E20+E43+E44+E45+E46)*3` | parity |

> **S5 修正说明（2026-09-10）**：原 Excel 该单元格末项误写为 `E12`（区域人口密度 C9），与前三项的「失能率」量纲不一致，使结果虚高约 32 万倍（2.26 亿人）。业务方确认末项应为 `E11`（80 岁以上失能率 C8），已修正。修正后 S5 与 S3 公式结构相同、数值相同（689.89），两者是否应共用同一算式仍待业务方复核，见 [`u1-known-issues.md`](./u1-known-issues.md)。

## 月度投影顺序

1. 依据 `D1/D2/D3` 生成筹备期、启动期、平台期。
2. 按 `S5*S8` 和启动期线性爬坡计算签约客户。
3. 计算单客月收入、长护险收入、基金/个人支付和辅助收入。
4. 计算护理员、销售、护士变动成本。
5. 计算管理、租金、系统、培训、水电、办公、GR、合规和两项摊销固定成本。
6. 计算毛利润、净利润、毛利率、净利率、累计净利润和累计现金流。
7. 计算现金流回正标记、回正月份候选值和平台期盈亏平衡客户数。

## 结果基准

当前基准输入的回归值位于 `u1-baseline.json`，包含 24 个月关键缓存样本。金额比较使用明确容差，月份、阶段和错误码精确匹配。
