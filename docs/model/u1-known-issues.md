# U1 已知问题与待业务确认

本页对应 [`u1.issues.json`](../../packages/model-spec/issues/u1.issues.json)。这些问题是当前 Excel 的复刻风险，不代表本系统已经确认其为业务错误。

## `控制台!E32`：疑似单元格引用

- **问题代码**：`SUSPECTED_CELL_REFERENCE`
- **当前行为**：站点覆盖失能客户上限公式最后一项使用 `E12*0.1`。
- **疑点**：`E12` 是区域人口密度；按字段语义，最后一项可能应使用 80 岁以上失能率所在的 `E11`。
- **本版本处理**：原样保留 Excel 引用，结果中标记 `needs_business_confirmation`，不做限幅或替换。

## `阶段汇总表!B12`：筹备期净利率 `DIV0`

- **问题代码**：`DIV0_IN_SUMMARY`
- **当前行为**：筹备期累计收入为 0，`B8/B5` 返回 `#DIV/0!`。
- **本版本处理**：使用 `FormulaValue(status="formula_error", error_code="DIV0")` 表达，不改成 0、不改成空值。

## `核心指标卡!C9` / `AB32`：累计序列求和

- **问题代码**：`CUMULATIVE_SERIES_SUM`
- **当前行为**：`AB32 = SUM(B32:Y32)`，把每个月的累计净利润再次求和。
- **疑点**：如果业务要的是第 24 个月累计净利润，通常应直接取 `Y32`；但当前版本不替换 Excel 逻辑。
- **本版本处理**：headline 指标继续复刻 `SUM(B32:Y32)`，同时在问题列表中标记待业务确认。

## 数量级异常

基准输入会产生非常大的站点客户数和收入结果。这一版本不通过四舍五入、限幅、`IFERROR` 或隐式单位换算改变结果；后续业务评审需确认城市总量、区域总量、站点覆盖范围和目标市场覆盖率的边界关系。
