# U1 参数字典

参数 JSON 是运行时的唯一机器可读来源：[`u1.parameters.json`](../../packages/model-spec/parameters/u1.parameters.json)。本页解释分组、字段边界和当前基准输入，不替代 JSON 中的单元格映射。

## 参数元数据字段

| 字段 | 说明 |
|---|---|
| `id` | Excel 控制台参数的稳定编号 |
| `name` | 业务展示名称 |
| `unit` | 展示与校验使用的单位 |
| `excelCell` | 原始工作簿控制台单元格 |
| `inputKind` | `manual`、`reference_or_manual` 或 `formula` |
| `stage` | P0/P1/P2 使用阶段 |
| `sourceType` | 字段来源，仅三类：内部填写、自动爬虫、公式自动 |
| `required` | 是否为当前公式链所需输入 |
| `parityStatus` | `parity` 或 `needs_business_confirmation` |

## 分组

| 分组 | 编号 | 当前职责 |
|---|---|---|
| 城市与市场 | C1-C13 | 城市、人口、年龄结构、失能率、人口密度、医保和区域面积 |
| 政策与服务 | P1-P11 | 单价、支付比例、最低人员配置、服务时长和政策开关 |
| 站点 | S1-S8 | 覆盖半径、工作天数、面积、租金和目标覆盖率 |
| 成本与投资 | B1-B16 | 护理员、护士、管理、系统、合规、装修、物料和初始投资 |
| 发展阶段 | D1-D8 | 筹备期、启动期、平台期及爬坡和效率假设 |
| 效率与风险 | E1-E8 | 利用率、流失、提成、回款和坏账假设 |
| 辅助收入 | A1-A6 | 辅具、消费券、亲情照护和政府购买服务 |
| 进入模式 | Z1-Z5 | 自营、收购、联营、资源复用和场景模式 |

## 空值规则

`null`、数字 `0` 和公式错误是三种不同状态。当前基准中的 `C11` 为空，但不在第一版实际公式驱动链中，因此不会被错误地当作 0，也不会阻断基准计算；缺少实际使用的必填驱动参数会返回 `blocked`。
